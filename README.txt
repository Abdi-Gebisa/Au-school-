AUSSS multi-page website starter

Files:
- home.html — Home page
- about.html — About the School
- academics.html — Academics
- news.html — News and announcements
- achievements.html — Achievements
- downloads.html — Downloads
- contact.html — Contact
- style.css — shared styles
- site.js — shared navigation and footer year
- news.js — public Supabase announcements reader

Upload all files together into the ROOT of the existing GitHub Pages repository. Keep the existing index.html until you are ready to make home.html the landing page. GitHub Pages opens index.html by default, so either rename home.html to index.html after backing up the current one, or keep index.html as a small redirect to home.html. Do not upload a Supabase service-role/secret key. Replace PASTE_YOUR_SB_PUBLISHABLE_KEY_HERE in news.js with the project's publishable key.

The page text includes placeholders that should be verified/approved by the school before public launch. The admin dashboard is not included in these public pages; it should remain a separate admin.html file.
